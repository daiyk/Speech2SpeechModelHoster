# App icon

Generated with the built-in image generation tool. Original artwork is preserved
in AppIcon.png, including alpha. The build script uses sips and iconutil to create
all macOS icon resolutions and the ICNS bundle resource.

## Generation prompt

Use case: logo-brand. Asset: unique macOS application icon for Reachy Mini Speech, a private local robot speech app. Create one beautifully crafted, instantly legible 1024x1024 icon: friendly ivory robot head with two expressive dark circular eyes and two short antennae, integrated with a small sculpted speech waveform below the face. Polished soft 3D ceramic relief, restrained depth, rounded forms, strong silhouette at small sizes. Centered on a rich teal rounded-square macOS icon tile, subtle aqua light, generous safe margin. The tile occupies about 88% of the square canvas with transparent outside corners. Front view, no perspective. No lettering, no words, no watermark, no extra objects. Production-quality original app icon, not a presentation or mockup.
