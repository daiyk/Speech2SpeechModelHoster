# Changelog

## v0.2.1 — 2026-11-25

- Open the DMG and drag Reachy Mini Speech onto the Applications shortcut to install it. Existing release installations receive the same disk image through the in-app updater.

## v0.2.0 — 2026-11-25

- Run the speech server from a native Apple Silicon app. First launch sets up Python and the pinned speech models in your user Library.
- Switch between local and LAN access, copy the connection address, and see connected clients, conversation transcripts, and diagnostics.
- Install the macOS app from GitHub Releases. Enable automatic update checks or choose **Reachy Mini Speech → Check for Updates…** to install a signed update. Downloaded models carry over.

## 2026-11-04

- Added the terminal launchers for the local Hugging Face speech server, Mac model profiles, and Realtime connection diagnostics.
